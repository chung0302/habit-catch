# 习惯打卡 habit-catch

一个极简单的习惯追踪页面：点灯式记录想坚持的习惯，计数式记录想改掉的坏习惯。
纯 HTML/CSS/JS 单文件，零依赖、无后端、无账号，数据只保存在你自己的浏览器里。

## 用法

直接打开 `index.html`，或访问 GitHub Pages 上的在线版本。

- **想坚持的**：输入习惯名添加，每天完成的就点一下圆点点亮。圆点下方是最近 7 天，名称下方是连续天数。
- **想改掉的**：点数字记一次，旁边的小 `−` 用来退回（数字为 0 时会自动隐藏）。右侧数字是"及时意识到并控制住"的次数，用强调色标出。
- **数据**：存在浏览器的 localStorage（键名 `habit-tracker-v1`）。刷新、关机都不丢；换浏览器、换电脑或清理浏览器数据会清空。

## 发布到 GitHub Pages

仓库根目录的 `index.html` 就是首页，无需改动。在仓库的 **Settings → Pages** 里，
把 Source 设为 `main` 分支的 `/ (root)`，保存后大约一分钟生效，网址形如
`https://chung0302.github.io/habit-catch/`。

之后每次 `git push`，同一个网址会自动更新；因为 CDN 有约 10 分钟的缓存，
偶尔需要 Ctrl+F5 强制刷新才能看到最新版。

## 说明

整个程序就是一个文件，没有任何构建步骤，方便直接阅读和修改。
